# Frontend

La aplicación Razor Pages está en `IPC2_Proy03.Frontend` y forma parte de la solución.

Ejecuta ambos proyectos con el perfil `http`: el backend usa `http://localhost:5280`
y el frontend usa `http://localhost:5080`. La página `/EnviarMensaje` permite cargar JSON.
Las demás pantallas todavía están pendientes de implementar.
